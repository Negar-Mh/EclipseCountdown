# Glassmorphism Product Page

A premium e-commerce product page UI featuring a full glassmorphism design. This project showcases a futuristic and elegant user interface inspired by Apple's Vision Pro OS.

## Key Features

*   **Glassmorphism UI:** Translucent, frosted-glass panels with blurred backgrounds.
*   **Split Layout:** A large 3D product render on the left and a detailed info panel on the right.
*   **Interactive Elements:** Floating glass buttons, holographic hover effects, and micro-animations.
*   **Premium Typography:** A clean and high-contrast font pairing for a modern aesthetic.
*   **Responsive Design:** The layout adapts to different screen sizes.

## Technologies Used

*   HTML5
*   CSS3
*   JavaScript
